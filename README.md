# Planejador de Evento Escolar

Projeto Flutter feito para a atividade escolar.

## Estrutura

- `lib/main.dart` - inicia o aplicativo.
- `lib/models/atividade.dart` - guarda os dados e regras da atividade.
- `lib/screens/configuracao_page.dart` - Tela 1: configuração.
- `lib/screens/resumo_page.dart` - Tela 2: resumo e análise.
- `lib/widgets/preview_atividade.dart` - pré-visualização.
- `lib/widgets/tabela_resumo.dart` - tabela da segunda tela.
- `test/` - teste simples.

## Executar

No terminal, dentro da pasta:

```bash
flutter pub get
flutter run -d chrome
```

## Plataformas

As pastas de plataforma podem ser geradas automaticamente pelo Flutter:

```bash
flutter create .
```

Depois:

```bash
flutter pub get
flutter run -d chrome
```
